# Bee-Live

A smart academic performance tracker that helps students improve their course grades with AI-powered study recommendations.

## Features

- **Course Management**: Add courses and rate your performance (0-10 scale)
- **AI Study Advice**: Get personalized improvement tips generated by OpenAI
- **Performance Dashboard**: View your average score, strong courses, and courses needing attention
- **Course Ranking**: Automatically identifies your weakest courses to prioritize
- **Editable Scores**: Update course ratings as you improve
- **Goal Tracking**: Set and manage academic goals
- **Secure Authentication**: Sign up and log in with AWS Cognito
